# Contributing

Thank you for helping to improve **Awesome Event-B**! This project is released
with a [Code of Conduct](code-of-conduct.md). By participating you agree to
abide by its terms.

## Guidelines

Please make sure your pull request follows these rules:

- Search the list and open pull requests first to avoid duplicates.
- Make one pull request per suggestion so each can be reviewed on its own.
- Use the format `[Name](link) - Description.` for every entry.
- Write a concise, objective description that ends with a period. Avoid
  marketing language.
- Add the entry to the section that fits best, in a sensible order. New
  categories are welcome if they improve the structure.
- Only suggest resources that are high quality and actively maintained. If a
  resource is abandoned or its link is dead, it does not belong here.
- Check your spelling and grammar, and make sure the link works.
- The pull request and commit should have a meaningful title.

## Validating your changes

The list is checked with [awesome-lint](https://github.com/sindresorhus/awesome-lint).
Run it locally before opening a pull request:

```sh
npx awesome-lint
```

Fix any reported issues so the CI check passes.

## Updating your pull request

If a maintainer asks for changes, edit the existing pull request rather than
opening a new one. There is no need to start over.

Thank you for your contribution!
